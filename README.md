Sobre o portfólio

Este repositório contém as atividades da Parte 1 do Portfólio de Programação Matemática, desenvolvidas utilizando uma linguagem Python.

Atividade 1 – Teoria dos Conjuntos

Nesta atividade são obras operações e propriedades de conjuntos, incluindo:

União de conjuntos;
Interseção;
Diferença entre conjuntos;
Cardinalidade;
Conjunto das partes;
Partição;
Produto cartesiano;
Verificação de subconjuntos.

Arquivo: P1/atividade_01_conjuntos/conjuntos.py

Atividade 2 – Divisibilidade, MDC e MMC

Nesta atividade são trabalhados conceitos de divisão, incluindo:

Divisão inteira;
Resta da divisão;
Algoritmo de Euclides;
Cálculo do MDC;
Cálculo do MMC.

Arquivo: P1/atividade_02_divisibilidade/divisibilidade.py

Executar Como
Abra o projeto no Visual Studio Code.
Entre na massa da atividade que deseja executar.
Abra o arquivo .py.
Abra o terminal do VS Code.
Execute o programa com:
python conjuntos.py

Parágrafo a Atividade 2:

python divisibilidade.py
Digite os valores solicitados pelo programa.
